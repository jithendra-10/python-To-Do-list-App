# To-Do List App ✅

  A simple To-Do List GUI application** built using **Python (Tkinter)** to help manage daily tasks efficiently.

## 📌 Features:
✅ Add & Remove tasks** dynamically  
✅ Mark tasks as completed**  
✅ Save tasks** to a file for persistence  
✅ Minimal & clean Tkinter UI

## 🚀 Installation:
1. Clone the repository:
   ```bash
   git clone https://github.com/jithendra-10/todo-list-app.git
   cd todo-list-app
2. Install dependencies:
  pip install tkinter
3. Run the app:
  python todo.py
